# Herakleez 💪

**Herakleez** is a mobile workout tracking app designed to help you monitor your workouts, track your body progress, and keep a history of your fitness journey.

## ✨ Features

### 🏋️ Workout Tracking

Keep detailed records of every workout, including:

* Number of workouts completed per week
* Workout duration
* Exercises performed
* Sets and reps for each exercise
* Maximum weight used for each exercise

### ⚖️ Weight Tracking

Track your body weight over time and monitor your progress through your fitness journey.

### 📊 BMI Chart

View your BMI and track changes over time with an easy-to-understand chart.

### 📸 Muscle Progress Tracking

Take progress photos directly through the app to visually track changes in your physique over time.

### 🧍 Exercise Library

Browse all available exercises with animated demonstrations organized by body part, making it easier to understand how each exercise should be performed.

### 📜 Workout History

View your previous workouts and review your training history, including exercises, sets, reps, weights, and workout duration.

### 🏠 Dashboard

Get a quick overview of your training activity from the dashboard, including your previous workout and other useful workout information.

## 🎯 Purpose

Herakleez is built to make workout tracking simple while giving you a clear view of your progress over time.

Whether you want to improve your strength, build muscle, or simply stay consistent with your workouts, Herakleez helps you keep everything organized in one place.

## 🛠️ Built With

* Vue.js
* Capacitor
* SQLite
* Tailwind CSS
* JavaScript

## 📱 Platform

Herakleez is developed as a mobile application using **Capacitor**, allowing the application to run as a native mobile app while using modern web technologies.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Android Studio
* Android SDK

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate into the project:

```bash
cd herakleez
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

For Android development:

```bash
npx cap sync android
npx cap open android
```
